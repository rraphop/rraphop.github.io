# 프로그램 다운로드 파일

이 폴더에는 홈페이지에서 직접 배포할 공개 EXE 또는 ZIP 파일을 넣습니다.
아직 실제 프로그램 파일은 들어 있지 않습니다.

예: `teacher-note-v1.0.zip` 파일을 이 폴더에 넣고 Git으로 커밋·푸시합니다.
32MB 파일은 GitHub 웹 업로드 한도(25MiB)를 넘으므로 로컬 Git 또는 GitHub Desktop으로 올려야 합니다.

배포 완료 후 자료실 글에 다음 값을 입력합니다.

- 다운로드 주소: `/downloads/teacher-note-v1.0.zip`
- 다운로드 파일명: `교무수첩.zip`

실제 파일은 영문 이름으로 보관하고, 방문자의 브라우저에는 한글 저장 이름을 전달합니다.
다운로드 파일명의 확장자는 실제 파일과 같아야 합니다. EXE라면 두 항목 모두 `.exe`를 사용합니다.
파일 경로는 대소문자를 구분합니다. 파일명을 바꾸거나 새 버전을 올리면 게시글 주소도 함께 수정합니다.

GitHub Releases 링크도 자료실에서 계속 사용할 수 있지만, 다른 도메인의 파일이므로 다운로드 파일명 항목은 비워 두어야 합니다.
